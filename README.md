# Simple Quiz — квиз по JavaScript

Небольшой учебный квиз по массивам и объектам в JavaScript. При каждом прохождении из банка в 20 вопросов случайно выбираются 10; есть вопросы с одним и с несколькими правильными ответами.

**Сайт:** [https://mmf-web.github.io/simple-quiz/](https://mmf-web.github.io/simple-quiz/)

## Возможности

- 20 вопросов в банке, на экране — 10 случайных
- Одиночный и множественный выбор
- Проверка ответов и экран результатов с процентом и разбором ошибок
- Адаптивная вёрстка (Tailwind CSS)

## Структура проекта

| Файл | Назначение |
|------|------------|
| `index.html` | Разметка страницы |
| `questions.js` | Банк вопросов (`allQuestions`) |
| `main.js` | Выбор случайных вопросов, рендер формы и результатов |
| `.github/workflows/static.yml` | Деплой на GitHub Pages при push в `main` |

## Локальный запуск

Сборка не требуется — достаточно открыть `index.html` в браузере или поднять простой HTTP-сервер:

```bash
npx serve .
```

## Добавление вопросов

Новые вопросы добавляются в массив `allQuestions` в `questions.js`. Каждый объект:

```js
{
  question: 'Текст вопроса',
  options: ['вариант 1', 'вариант 2', ...],
  answers: ['правильный вариант'],
  type: 'single', // или 'multiple'
}
```

Количество вопросов в одной попытке задаётся константой `QUIZ_SIZE` в `main.js` (по умолчанию 10).
